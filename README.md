# Дорога — детская игра

Машинки едут по дороге в двух полосах: дальняя — встречная, ближняя — попутная.
Дорога начинается пустой: машины появляются после того, как учитель загрузит
рисунки детей. Рисунки лежат в `assets/cars/` и описываются в `cars.json`.

## Запуск локально

```sh
cd road
python3 -m http.server 8000
```

Откройте http://localhost:8000

Можно открыть и просто двойным щелчком по `index.html` — тогда `cars.json`
не загрузится, и дорога останется пустой. Загрузка и редактирование машин
происходят только на странице `admin.html`.

## Публикация на GitHub Pages

1. Создайте **публичный** репозиторий, например `road` (на бесплатном плане
   Pages работает только для публичных репозиториев).
2. Положите в **корень** репозитория содержимое этой папки:
   `index.html`, `admin.html`, `game.js`, `admin.js`,
   `image-processing.js`, `styles.css`, `admin.css`, `cars.json`, `assets/`.
3. В репозитории: **Settings → Pages → Deploy from a branch → main / (root) → Save**.
4. Через минуту сайт откроется по адресу `https://<логин>.github.io/road/`.

Если положить игру в подпапку другого репозитория, адрес будет другим —
тогда в настройках `admin.html` укажите репозиторий вручную.

## Загрузка рисунков с телефона

1. Создайте fine-grained токен GitHub:
   **Settings → Developer settings → Personal access tokens → Fine-grained tokens**.
   - Repository access: **Only select repositories** → ваш репозиторий.
   - Permissions → Repository permissions → **Contents: Read and write**.
2. На телефоне откройте `https://<логин>.github.io/road/admin.html`.
3. Введите `логин/репозиторий`, ветку `main` и токен, нажмите **Сохранить**.
4. Сфотографируйте или выберите сразу несколько рисунков. Лучше, чтобы лист
   занимал весь кадр; подойдёт и желтоватая бумага.
5. В ленте миниатюр: нажатие на превью отражает машину, **↻** поворачивает
   фото на 90°, **✂️** открывает ручную обрезку рамкой (мышь и touch),
   **×** убирает фото из подборки.
6. Если фон остался — увеличьте **Чувствительность фона**. Если пропали детали
   рисунка — уменьшите её. **Сочность линий** делает карандаш ярче.
7. Нажмите **Опубликовать на дороге**.
8. В блоке **«Сейчас на дороге»** видны все опубликованные машины. Кнопка 🗑
   удаляет запись из `cars.json` и PNG-файл из репозитория. Кнопка
   **«Убрать все с дороги»** очищает только `cars.json`, файлы остаются.

Страница делает один коммит: PNG в `assets/cars/` и обновлённый `cars.json`.
При удалении машины тоже создаётся один коммит: обновлённый `cars.json`
и удаление PNG. GitHub Pages пересоберёт сайт за 30–60 секунд, а игра на
компьютере подхватит изменения сама — без перезагрузки.

Токен хранится только в браузере телефона (`localStorage`) и в репозиторий
не попадает. Страница `admin.html` никуда не ссылается с игры.

## Как добавить машину вручную

1. Положите PNG (лучше с прозрачным фоном) в `assets/cars/`.
2. Добавьте запись в `cars.json`:

```json
{ "file": "assets/cars/moya-mashina.png", "name": "Моя машина", "facing": "right" }
```

`facing` — куда смотрит нос машины на рисунке: `"right"` или `"left"`.
Игра сама отзеркалит её для встречной полосы.

## Управление в игре

- Клик/тап по машине — сигнал и подпрыгивание.
- Кнопки справа сверху — скорость, звук, пауза.
- Машины добавляются и удаляются только на странице `admin.html`, поэтому
  главный экран остаётся чистым для проектора.

## Копия дороги для детей

Папка `kids/` — замороженная копия игры со своими `cars.json`,
`assets/cars` и `assets/audio`. Правки в админке на неё не влияют.
Адрес: https://deripasskaya.github.io/RoadDraw/kids/

Чтобы обновить копию после добавления машин, пересоберите `kids/` из
текущих `cars.json` и `assets/cars` и закоммитьте папку.
