Добавить машину

Подключение к GitHub

Проверьте данные репозитория и токен.

Как получить токен
  1. Откройте github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Нажмите Generate new token.
  3. В Repository access выберите Only select repositories и укажите репозиторий с игрой.
  4. В Repository permissions найдите Contents и поставьте Read and write.
  5. Создайте токен и скопируйте его сюда.

Токен хранится только в этом браузере и не попадает в код сайта. На чужом компьютере не сохраняйте его.

Двигайте ползунки — превью обновится сразу. «Чувствительность» убирает фон, «Сочность линий» делает штрихи ярче. 50% — авто-уровень.

Нос машины на превью должен смотреть вправо. Если он смотрит влево — нажмите «Отразить».

Дорога

Убрать все машины сразу. Рисунки останутся в репозитории — их можно вернуть вручную.

🎉

Готово!

GitHub пересобирает сайт. Игра на компьютере подхватит новые машины сама — обычно в течение минуты.

Открыть игру

Страница никуда не ссылается с игры. Без токена она не может ничего изменить в репозитории.
