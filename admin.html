Добавить машину

Подключение к GitHub

Проверьте данные репозитория и токен.

Как получить токен
  1. Откройте github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Нажмите Generate new token.
  3. В Repository access выберите Only select repositories и укажите репозиторий с игрой.
  4. В Repository permissions найдите Contents и поставьте Read and write.
  5. Создайте токен и скопируйте его сюда.

Токен хранится только в этом браузере и не попадает в код сайта. На чужом компьютере не сохраняйте его.

Двигайте ползунки — превью обновится сразу. «Чувствительность фона» помогает убрать тень и сложный фон, «Сочность линий» делает карандаш ярче. 50% — авто-уровень.

Нажмите на миниатюру, чтобы отразить машину. ↻ — повернуть на 90°, ✂️ — обрезать рамкой, × — убрать из подборки.

Сейчас на дороге

Все опубликованные машины из cars.json. Удаление убирает запись и PNG-файл из репозитория.

Кнопка «Убрать все с дороги» очищает только cars.json. PNG-файлы остаются в репозитории.
